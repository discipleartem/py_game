# Terminal Text Adventure (Python)

Консольная текстовая ролевая игра, написанная на Python. Игрок перемещается по локациям, исследует мир и взаимодействует с объектами через текстовые команды.

## 🛠 Технологии

`Python 3.12`

## 📦 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/discipleartem/py_game.git
   cd py_game
   ```

2. Установите зависимости (если используются):
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите игру:
   ```bash
   python main.py
   ```
